# Sigmaboy

**Sigma scheduler for Qwen-Image 2.1 Turbo (8 steps).**

Sigmaboy fixes image artifacts, broken geometry, and mush caused by default schedulers.

One slider. Interpolates between three tuned sigma profiles.

Usage
Connect sigmas → sampler

Slider 1.0 = base profile (recommended)

Slider >1.0 = more aggressive

Sampler: Euler Ancestral, simple, 8 steps, CFG 1.0
